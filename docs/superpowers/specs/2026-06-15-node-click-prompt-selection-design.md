# 节点点击提示框与多选框视觉设计

## 目标

- 鼠标悬停节点时不显示下方提示词面板。
- 框选节点只改变选择状态，不打开任何节点的提示词面板。
- 左键点击普通生成节点的空白区域、预览区域或正文区域时，打开该节点的提示词面板。
- 移除节点右下角原有的提示词按钮。
- 多选框使用与画布节点一致的深色玻璃质感，并紧凑包围已选节点。

## 交互规则

- 点击文本、图像或视频生成节点时，仅打开当前节点的提示词面板，并关闭其他节点的提示词面板。
- 点击按钮、输入框、文本框、视频控件、链接或提示词面板内部时，不重复触发节点点击。
- 素材节点和组节点没有提示词面板，因此点击时不打开面板。
- 点击空白画布时关闭已打开的提示词面板。
- React Flow 的框选事件只维护 `selected` 状态，不修改 `promptOpen`。

## 视觉规则

- 删除 `.prompt-toggle` 按钮及相关样式。
- 提示词面板仅由 `.prompt-pop.open` 控制可见性，不再响应父节点悬停。
- 多选框缩小外边距，使用半透明渐变背景、细边框、圆角和柔和阴影。
- 保留多选框上方打组工具条和左右连接加号。

## 验证

- 静态回归检查验证不存在 `prompt-toggle`，节点点击会更新 `promptOpen`，悬停选择器不会打开提示词面板。
- TypeScript、已有项目检查和生产构建通过。
- 浏览器验证节点悬停、节点点击、空白画布点击和多选框视觉。
